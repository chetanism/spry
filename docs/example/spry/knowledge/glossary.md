# Glossary

| Term | Means | Don't say |
|---|---|---|
| Member | a person who may borrow books from the library | patron, borrower |
| Librarian | a person who works the desk | clerk, staff member |
| Library card | the card with a member's number and barcode | membership card |
| Desk | the screen a librarian uses to lend books and record returns | counter, POS |
| Lend | a librarian gives a book to a member, recorded as a loan | check out, issue a book |
| Loan | the record that a member has a book, from lending to return | checkout |
| Return | the book comes back and its loan ends | check in, take back |
| Due date | the day a loan should end | return date, deadline |
| Overdue | a loan still open after its due date | late, past due |
