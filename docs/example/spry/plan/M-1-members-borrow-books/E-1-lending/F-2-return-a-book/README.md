# F-2 · Return a book

## Summary

- A librarian records a return by scanning the book; it is available to lend again straight away.

## Who uses it

- **Librarian** — at the desk.

## How it works

1. The librarian scans the book → the desk shows who has it and its due date.
2. The librarian presses **Return** → the desk confirms; the book is available.

## Rules

- **R-1** A return is recorded against the loan, never deleted from the member's history.
