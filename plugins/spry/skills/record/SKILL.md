# spry — record

- **Procedure:** `spry/process/recording.md`. Read `chat.md` and `writing.md` beside it.
- **Kind** from `$ARGUMENTS`, or the conversation; ask when unsure.
- A decision is created with `spry.py new decision`, never by picking a number — with `mint: main`
  that takes the ID on the main branch.
- Search before writing: extend an existing entry rather than adding a second about the same thing.
